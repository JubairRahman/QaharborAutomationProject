An automated test suite for the **QA Harbor** platform, built with **Selenium WebDriver**, **Pytest**, and **Page Object Model (POM)**. Designed to validate the user **registration** and **login** flows with robust reporting and best practices.

---

## 🔧 Tech Stack

- **Language:** Python 3.9+
- **Libraries & Tools:**
  - Selenium WebDriver
  - Pytest
  - WebDriverWait (explicit waits)
  - HTML Test Reporting
  - `python-dotenv` for managing environment variables
- **Version Control:** Git + GitHub

- ⏱️ WebDriverWait for smart synchronization

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/nipaDey/QaharborAutomationProject.git
cd QaharborAutomationProject
```

### 2. Install dependencies
```bash
pip install -r 
```

### 3. Configure environment variables
> Create a `.env `file in the root directory

### 4. Run tests

```bash
pytest --html=reports/report.html
```
